# Sing-box v1.27: Snell Link Export and Relay Bug Fixes Design

**Status:** Approved design

**Source requirements:** `Singbox v1.27需求.md`

**Target:** `one-singbox` (v1.27) script updates to fix relay port generation / listing bugs, and add copyable Snell share formats (sing-box URI and Surge configuration).

---

## 1. Goal

1. **Fix Relay Port Input Bug**: Allow users to press Enter (blank input) to automatically allocate an unused listening port during interactive relay creation, eliminating false validation errors from `ask()`.
2. **Clean Up Relay Menu Listing**: Remove the redundant and error-prone prompt `请输入要查看的中转本地端口` after `relay_list`, making menu option 2 a straightforward listing display.
3. **Provide Snell Export Formats**: Output exactly two copyable formats for Snell nodes upon creation and inspection:
   - **sing-box 格式 (URI)**: `snell://<psk>@<address>:<port>?version=5#<node_name>`
   - **Surge 格式 (单行配置)**: `<node_name> = snell, <address>, <port>, psk=<psk>, version=5`
4. **Omit Redundant QR Code**: Explicitly keep QR code generation unsupported for Snell nodes to maintain minimalism and avoid unnecessary features.

---

## 2. Scope & Design Decisions

### 2.1 Relay Port Input (`relay_add`)
- **Current Issue**: The variable in `ask string local_port` matches `grep port <<<$is_ask_set` inside `ask()`. The helper performs `is_test port "$REPLY"` which strictly requires a numeric port in 1-65535, rejecting empty inputs.
- **Decision**:
  - Prompt text: `请输入本地监听端口 (直接回车自动生成):`.
  - Variable used in `ask` changed to `relay_port_input` to bypass the built-in numeric-only constraint.
  - If input is empty (user presses Enter): automatically call `get_port` to find an unused port not in conflict with active listeners or existing configurations (`config_port_used`), and print `自动分配本地端口: <port>`.
  - If input is non-empty: validate with `is_test port`, `is_test port_used`, and `config_port_used`.

### 2.2 Relay Menu List (`relay_menu`)
- **Current Issue**: Menu item 2 (`"中转列表/信息"`) runs `relay_list` and then prompts `ask string local_port "请输入要查看的中转本地端口 (留空跳过):"`. If left blank, it errors out because the variable contains `port`. Moreover, `relay_list` already displays all necessary relay details.
- **Decision**:
  - Rename menu item 2 to `"中转列表"`.
  - When selected, execute `relay_list` and finish cleanly without prompting for a local port.
  - CLI command `sing-box relay info <port>` remains available for targeted scripting.

### 2.3 Snell Export Formats (`info` & `url`)
- **Export Formats**:
  1. **sing-box 格式 (URI)**:
     - No obfs (`none`): `snell://${snell_psk}@${is_addr}:${port}?version=${snell_version}#${is_node_name}`
     - HTTP obfs (`http`): `snell://${snell_psk}@${is_addr}:${port}?version=${snell_version}&obfs=http#${is_node_name}`
  2. **Surge 格式 (单行配置)**:
     - No obfs (`none`): `${is_node_name} = snell, ${is_addr}, ${port}, psk=${snell_psk}, version=${snell_version}`
     - HTTP obfs (`http`): `${is_node_name} = snell, ${is_addr}, ${port}, psk=${snell_psk}, version=${snell_version}, obfs=http`
- **Command Behavior**:
  - `sing-box info [tag/port]` and node creation:
    - Display standard parameter table.
    - Display `------------- URL 链接 -------------` with the sing-box URI.
    - Display `------------- Surge 配置 -------------` with the Surge configuration line.
  - `sing-box url [tag/port]`:
    - Display `------------- <config> & URL 链接 -------------` with the sing-box URI.
    - Display `------------- Surge 配置 -------------` with the Surge configuration line.
  - `sing-box qr [tag/port]`:
    - Output error: `Snell 不支持二维码生成，请使用 URL 链接或 Surge 配置`.

## 3. Component Changes

### 3.1 `src/core.sh` and `core.sh`
- **`relay_add()`**:
  - Read into `relay_port_input` via `ask string relay_port_input "请输入本地监听端口 (直接回车自动生成):"`.
  - Handle empty input by executing the `get_port` loop.
- **`relay_menu()`**:
  - Change `"中转列表/信息"` to `"中转列表"`.
  - Remove `ask string local_port` and the subsequent `relay_info` invocation in branch 2.
- **`info()` (case `snell`)**:
  - Compute `is_url` and `is_surge_str`.
  - Render `Surge 配置` section when `is_surge_str` is non-empty.
- **`url_qr()`**:
  - Allow Snell for `url` and output both `is_url` and `is_surge_str`.
  - Keep Snell blocked with clear error guidance on `qr`.

### 3.2 `sing-box.sh` & Documentation
- Bump `is_sh_ver` to `v1.27` in `sing-box.sh`.
- Update `src/help.sh` and `README.md` to remove obsolete notes saying Snell does not support URLs, and document the Snell URL / Surge export capability.
