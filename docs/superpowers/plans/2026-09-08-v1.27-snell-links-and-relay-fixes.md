# Sing-box v1.27: Snell Link Export and Relay Bug Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix relay port interactive auto-generation (direct Enter) and menu listing prompts, and implement dual-format Snell export (sing-box URI and Surge configuration) while keeping QR code unsupported.

**Architecture:** Update `relay_add` to accept Enter without triggering `ask()`'s numeric port check, clean up `relay_menu` to display the list cleanly, extend `info()` and `url_qr()` in `src/core.sh` and `core.sh` to generate and display sing-box URI and Surge config for Snell while failing closed on `qr`, bump version to v1.27, and expand automated test suites.

**Tech Stack:** Bash, sing-box JSON configuration, jq, Linux networking utilities.

## Global Constraints
- Target version: `sing-box >= 1.14.0` for Snell v5.
- Dual-file core parity: Every behavior change to `src/core.sh` must be applied identically to root `core.sh`.
- Minimal changes: Do not modify unrelated protocols, ask validations, or command flows.
- Automated tests must run and pass in both `core.sh` and `src/core.sh`.

```bash
relay_add() {
    local local_port=$1 remote_addr=$2 remote_port=$3
    if [[ ! $local_port ]]; then
        local relay_port_input
        ask string relay_port_input "请输入本地监听端口 (直接回车自动生成):"
        local_port=$relay_port_input
    fi
    if [[ -z $local_port ]]; then
        while :; do
            get_port
            local_port=$tmp_port
            config_port_used "$local_port" || break
        done
        msg "自动分配本地端口: $local_port"
    fi
    local_port=$(echo "$local_port" | tr -d ' ')
    [[ $(is_test port "$local_port") ]] || err "($local_port) 不是一个有效的端口."
    [[ $(is_test port_used "$local_port") ]] && err "本地端口 ($local_port) 已被占用."
    config_port_used "$local_port" && err "本地端口 ($local_port) 已被现有配置占用."
```
